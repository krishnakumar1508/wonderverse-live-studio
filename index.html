01 · Source

Best with direct MP4 or HLS/M3U8 media URLs. YouTube watch-page links usually cannot be relayed directly.

02 · Destinations

Copy server URL and stream key from each platform's live dashboard. Keys are sent only to this server's API over your connection; use HTTPS when deployed publicly.

Configure one or both destinations. Never share your stream keys.

03 · Control room

Connecting to server…
This needs a deployed server with FFmpeg installed and a strong ADMIN_PASSWORD. A browser-only HTML page cannot broadcast to platforms by itself. A successful start response means the encoder started; confirm “live” in both platform dashboards.

Deployment checklist

Run this app on a VPS/server with FFmpeg installed. Keep it behind HTTPS, use a strong password, and don't expose stream keys in public code or screenshots. This starter does not implement account management or persistent stream history.

Input support depends on FFmpeg and source accessibility. Platform watch pages, DRM-protected streams, and sources requiring browser login are not reliable relay inputs.
